# 🔥 Olive & Flame — Restaurant Website

A modern, elegant, and responsive restaurant website designed to showcase a premium dining experience. **Olive & Flame** features an inviting homepage, a dedicated food menu, and an about page with restaurant information and contact details.

## 🌐 Live Demo

**Live Website:** [View Olive & Flame](YOUR_NETLIFY_SITE_URL)

## ✨ Features

- **Elegant Homepage** — A welcoming hero section with clear navigation and calls to action.
- **Featured Dishes** — Highlights selected dishes with images, descriptions, prices, and menu links.
- **Dedicated Menu Page** — A separate page for exploring the restaurant's food offerings.
- **About & Contact Page** — Restaurant information and a contact section.
- **Table Reservation Navigation** — Convenient links to the reservation/contact section.
- **Responsive Navigation** — Navigation menu with a mobile hamburger control.
- **Modern Visual Design** — Food photography, typography, icons, and carefully styled content sections.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Layout, styling, and responsive presentation
- **JavaScript** — Interactive website functionality
- **Google Fonts** — Typography
- **Font Awesome** — Icons

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Fiza-batool/OLIVE-AND-FLAME.git
   ```

2. Open the project folder:

   ```bash
   cd OLIVE-AND-FLAME
   ```

3. Open `index.html` in your browser to explore the website.
